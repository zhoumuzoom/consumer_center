使用流程

给agent安装飞书CLI工具

首先为 Claude Code agent 安装飞书 CLI 工具（lark-cli）：

# 安装飞书 CLI 工具 npm install -g @larksuite/cli # 验证安装 lark-cli --version

安装完成后，初始化飞书配置：

# 初始化飞书配置（会引导完成应用配置） lark-cli config init # 完成用户认证 lark-cli auth login
⚠️ 注意：安装过程中需要配置飞书应用的 appId 和 appSecret，请提前在飞书开放平台创建应用并获取凭证
创建 system-analysis-doc Skill

安装飞书 CLI 工具后，使用 Claude Code 生成专属的 system-analysis-doc Skill：

请帮我创建一个 system-analysis-doc Skill，包含： 1. 系统分析文档的标准格式（9个章节） 2. 飞书 CLI 的使用方法（docs +create 命令） 3. 文档模板和示例 4. Mermaid 图表支持（架构图、流程图、ER图）

Claude 会自动生成完整的 Skill 文件，包含：

  • SKILL.md：Skill 定义和使用说明
  • 文档模板：9个标准章节的详细格式要求
  • 飞书集成：飞书 CLI 命令和 XML 格式说明
  • 示例参考：完整的文档示例
💡 提示：生成的 Skill 会保存在 .claude/skills/system-analysis-doc/ 目录下，后续可以直接使用
确认飞书CLI权限

生成 Skill 后，确认飞书 CLI 具有必要的权限：

# 检查认证状态和权限 lark-cli auth status --json --verify # 确保拥有以下权限： # - docx:document:create (创建文档) # - docs:document:write_only (写入文档) # - docs:document:read (读取文档)

如果权限不足，按提示完成授权：

# 按业务域授权 lark-cli auth login --domain docs # 或按具体 scope 授权 lark-cli auth login --scope "docx:document:create,docs:document:write_only"
运行 lark-cli auth login 后，选择需要授权的业务域（勾选 docs）
✅ 验证成功：当看到 "user": {"status": "ready"} 且 scope 包含文档相关权限时，表示配置成功

❓
常见问题

💡 为什么生成的文档内容不完整？
可能原因：项目代码不完整、缺少关键实现、没有提供足够的上下文信息。
解决方案：确保项目代码完整，提供详细的需求说明，补充缺失的实现代码。
💡 图表没有正确显示怎么办？
可能原因：Mermaid 语法错误、飞书版本不支持、图表过于复杂。
解决方案：检查 Mermaid 语法，简化图表内容，或拆分为多个简单图表。
💡 飞书文档创建失败？
可能原因：飞书认证过期、权限不足、网络问题。
解决方案：运行 lark-cli auth status --json --verify 检查认证状态，重新执行 lark-cli auth login --domain all 完成认证。
💡 如何修改已生成的文档？
方案一：直接在飞书编辑器中修改文档内容。
方案二：让 Claude 更新特定章节，例如："请更新这个飞书文档的第六章节，新增一张表..."
💡 文档内容太冗长怎么办？
解决方案：在生成前明确说明重点章节，要求只生成核心内容，或分模块生成独立文档。例如："请只生成系统分析文档的核心章节：项目背景、开发目标、系统架构图..."
