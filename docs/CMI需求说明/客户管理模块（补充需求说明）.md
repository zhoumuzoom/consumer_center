# 客户管理模块功能要求
## 整体概述    
实现要客集中化管理与可视化运营，汇聚集团 139 要客与国际公司中资出海要客数据，直观展示客户总量、看管率等核心指标，支持按行业、地域筛选下钻及清单增删改查。
通过多维度客户架构视图呈现客户组织架构与行业树，支持按客户树派发任务、维护海外节点信息及决策关键人信息。
客户分层依托分级标签与标准化建档流程实现精准纳管与认领分配；
360° 全景画像整合客户基础信息、业务数据及全球分支关系，支持多层级穿透分析。
引入AI能力一键生成结构化《行业客户洞察手册》，为战略决策与营销协同提供智能化支持。

## 明细要求
### 客户规模总览
1. 规模总览：承接并同步集团139要客清单、中资出海要客企业清单全量数据，完成多源要客数据的统一归集与融合处理，实现要客数据源标准化整合。统计全域要客总数量、已看管客户数量、客户看管率等核心规模指标，实现要客整体经营数据自动化、精准化输出。支持汇总分行业、分地域的客户存量数据与纳管状态数据，全方位呈现各维度要客储备与看管情况，支撑规模化数据统计分析。
2. 多维度要客数据筛选： 支持按行业、地域等多维度条件对要客数据进行精准筛选、过滤与查询，快速锁定目标维度客户数据。支持数据层级下钻查看，可从全局总览逐层下钻至细分行业、细分地域的客户明细与纳管详情，实现从宏观到微观的全层级数据分析。实现多维度数据联动查看、态势对比，直观呈现不同行业、不同地域下要客分布特征与看管差异，支撑精细化经营研判。
3. 要客清单CRUD维护管理：提供要客清单全量CRUD原子操作能力，支持要客清单数据新增、查询、修改、删除等常态化维护功能。支持业务人员自主维护要客基础信息、归属行业、所属地域、纳管状态等核心字段，适配日常业务调整需求。满足业务人员对要客清单的常态化运维管理需求，支持清单数据的动态更新与精准维护，适配业务动态变化的要客入库、信息更新、剔除调整等日常运营场景。

### 客户树管理
1. 集团直管要客客户树数据管理：对接并同步集团直管要客客户树结构化数据，完整吸纳客户层级、隶属关系、节点信息等核心内容，实现客户树数据标准化归集。对汇聚的客户树数据进行规整处理，搭建层级清晰、关联准确的集团要客客户树架构，保障数据关联性、完整性、一致性。为客户树筛选查询、统计分析、任务调度、节点信息上报等全场景功能提供稳定的数据支撑。
2. 客户树多维度统计分析：支持用户通过区域、客群类型、客户层级、节点属性等多维度条件自由组合筛选，精准过滤和查询目标客户树数据。基于客户树数据自动完成客群规模、节点数量、客户存量等指标统计，直观展示集团要客客群整体分布态势。同步提供客户树清单、实体客户清单两种展示形式，既支持层级树状查看，也支持明细列表查看，满足不同业务查询习惯。
3. 客户树维度任务调度：立足客户树层级化管理场景，解决传统任务调度无层级、节点信息反馈不及时、海外节点信息归集难的问题。支持基于客户树维度统筹调度营销及运营任务，同时支撑海外节点动态信息线上上传反馈。
4. 客户树信息CRUD维护管理：提供客户树信息完整的新增、查询、修改、删除原子操作能力，支撑客户树节点及关联信息常态化维护。支持业务人员自主调整客户树层级关系、节点归属、节点属性等核心内容，适配组织及客户架构动态调整场景。

### 决策关键人管理
1. 业务说明：面向国际地区客户运营场景，聚焦客户项目全流程决策链路信息管理，解决海外客户决策人员信息零散、权责部门不清晰、无统一维护入口的业务痛点。支持按国际地区维度统筹管理客户决策关联人信息，实现需求发起部门、方案部门、实施部门等关键决策主体信息的规范化录入与动态维护，完善客户关键人脉数据体系，为精准营销对接、项目落地协同、客情深度运营提供数据支撑。
2. 支持录入客户项目全链路关键信息，覆盖需求发起部门、方案设计部门、项目实施部门等核心决策及执行主体，完善客户决策链路数据台账。提供决策链信息新增、查询、修改、删除常态化维护能力，支持业务人员根据客户组织架构、项目团队变动情况实时更新数据，确保决策信息真实有效、动态同步。通过沉淀完整的客户决策链与关键部门信息，帮助一线人员精准匹配对接对应决策及执行主体，提升海外客户营销对接、项目推进、客情维护的精准度与效率。

### 行业树管理
1. 行业树全景数据可视化展示：以标准行业树结构可视化呈现全量行业新战客户分布，支持逐层展开各层级行业节点，实现行业客户体系层级化、结构化展示。各行业树节点聚合展示客户数量、客户看管率、下层节点数量、成树集团数量等关键指标，直观呈现各行业经营与客户纳管态势。支持用户自由切换、查看各层级行业树节点信息，可实现顶层行业概览、细分行业详情的逐层查看，满足多层级行业数据分析需求。
2. 客户分级管理与标签维护：针对行业客户分层运营、精准管控的业务需求，解决行业客户无等级划分、标签维护零散、无法批量更新的管理痛点。实现战略要客、重点客户的差异化分级管控，支持客户标签批量运维与动态更新，精准区分客户层级与客户属性，支撑差异化、精细化行业客户运营策略落地。建立行业客户分级体系，支持战略要客、重点客户两级分类管理，区分不同价值客户层级，适配差异化客户运营与维护标准。支持对行业客户标签进行批量新增、修改、替换操作，无需单条逐一维护，大幅提升客户标签运维效率。支持根据客户状态、合作层级、业务属性变化，实时动态更新客户标签，保障客户标签数据精准、有效，贴合最新业务现状。  

### 客户画像
聚合单个客户的完整信息视图，包括：基础信息、建档与看管信息、政策动态、公开的招标金额与信息化招标数量、历史项目订单、使用过的产品与方案、收入贡献及客情关系记录等。基于数据治理成果，平台将开发可视化界面，用于维护客户的海外分支机构及映射关系，并自动构建覆盖“总部—海外分支—本地实体”的可视化全球分支树。支持从客户画像页直接进行客户任务调度，并允许对客户树进行多层级穿透分析（例如，分析某集团亚太区各子公司的业务占比）。
行业客户洞察手册生成（AI谈参）：支持一键生成深度客户洞察报告。系统将自动整合该客户的海外分支信息、历史项目、所属行业趋势、相关出海政策、竞争对手动态及生态伙伴能力等信息，通过AI大语言模型按照预设的专业文档结构，自动生成一份结构化的《行业客户洞察手册》，赋能一线销售与策略制定。

### 集团数据上报管理
建设集团上数专题可视化页面，实现上报数据全量可视、异常明细可查；系统支持前端页面一键手动触发数据同步，同时配置定时调度任务，按照与集团敲定的接口规范自动完成周期数据同步，按需通过标准接口向集团要客系统报送国际要客全量数据，满足集团 139 工程常态化上数管控要求。
